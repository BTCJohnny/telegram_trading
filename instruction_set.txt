PROJECT: Hyperliquid Telegram Signal Trading Bot

DESCRIPTION:
This project is a Python-based trading bot designed to automate trade execution on the Hyperliquid decentralized exchange. It operates by reading trade signals from a designated Telegram channel, interpreting these signals (bullish/bearish entries, exit signals), dynamically sizing trades based on confidence levels, and managing positions (PnL, trailing stops). The bot aims for robustness through persistent storage of trade data and continuous monitoring of open positions.

CURRENT ARCHITECTURE:
The project is structured as a Python package, promoting modularity and clear separation of concerns.

your_bot_project/
├── .env                        # Centralized configuration (sensitive data, trading parameters)
├── main.py                     # The single entry point to run the bot
├── requirements.txt            # Python dependencies
├── README.md                   # Project documentation
├── .gitignore                  # Specifies files to ignore from version control (e.g., config.py)

└── bot_core/                   # Main Python package for bot logic
    ├── __init__.py             # Makes 'bot_core' a Python package
    ├── hyperliquid_api.py      # Low-level interaction with Hyperliquid API (fetching market data, placing orders, managing positions)
    ├── strategy_manager.py     # Implements enhanced trading logic (dynamic sizing, slippage control, bullish/bearish entry, Telegram-triggered exits)
    ├── trade_persistence.py    # Manages SQLite database for monitoring trades, runs continuous PnL/stop-loss monitoring thread
    ├── telegram_interface.py   # Handles Telegram API interaction (listening to messages, parsing signals using regex)
    └── utils.py                # Placeholder for common utility functions (currently mostly logging setup)

KEY COMPONENTS & RESPONSIBILITIES:

1.  .env:
    -   Purpose: Stores all sensitive API keys (Hyperliquid, Telegram) and adjustable trading parameters (e.g., FUNDING_PER_1_5_UNIT, default PnL targets).
    -   Security: Values are primarily sourced from environment variables for enhanced security.
    -   Location: Top-level directory.

2.  main.py:
    -   Purpose: The main entry point script. It orchestrates the initialization and startup of the bot's various services (Telegram listener, trade monitor).
    -   Location: Top-level directory.

3.  bot_core/hyperliquid_api.py (formerly hyperliquid_bot.py):
    -   Purpose: Encapsulates all direct interactions with the Hyperliquid exchange API.
    -   Functions: ask_bid, get_sz_px_decimals, limit_order, acct_bal, get_position, cancel_all_orders, kill_switch.
    -   Dependencies: eth-account, hyperliquid-sdk, requests.
    -   Key Feature: Initializes the Hyperliquid `LocalAccount` object.

4.  bot_core/strategy_manager.py (formerly additional_functions.py):
    -   Purpose: Implements the higher-level trading logic derived from signal interpretation.
    -   Functions: calculate_dynamic_sz, place_slippage_controlled_order, handle_bullish_entry_signal, handle_bearish_entry_signal, handle_telegram_exit_signal, calculate_trailing_stop_price.
    -   Dependencies: Imports functions from `hyperliquid_api.py` and configuration from `config.py`.

5.  bot_core/trade_persistence.py (formerly monitoring_trading.py):
    -   Purpose: Manages the SQLite database for persistent storage of bot-managed trades and runs a separate thread for continuous position monitoring (PnL, trailing stops).
    -   Functions: TradeMonitorDB class (add_trade, get_open_trades, update_trade_status), TradeMonitor class (start_monitoring, _monitor_loop).
    -   Dependencies: sqlite3, threading, imports from `hyperliquid_api.py` and `strategy_manager.py`.

6.  bot_core/telegram_interface.py (formerly telegram_listener.py):
    -   Purpose: The interface with Telegram. It listens for incoming messages, parses them using regex patterns, and dispatches the extracted signals to the `strategy_manager.py` functions.
    -   Main Function: `handle_telegram_message`.
    -   Dependencies: python-telegram-bot, imports from `config.py`, `strategy_manager.py`, and `trade_persistence.py`.
    -   Note: This file contains the regex patterns for signal detection (bullish entry, bearish entry, exit).

7.  bot_core/utils.py:
    -   Purpose: Currently empty. Intended for common utility functions (e.g., custom logging setup, data formatting helpers) that can be shared across modules.

CONFIGURATION DETAILS (in .env):
-   HYPERLIQUID_SECRET_KEY: Your Hyperliquid private key (0x...). Crucial.
-   TELEGRAM_BOT_TOKEN: The API token for your Telegram Bot (e.g., 123456:ABC...).
-   TELEGRAM_CHANNEL_ID: The numerical ID of your Telegram channel (typically a negative integer, e.g., -1001234567890).
-   FUNDING_PER_1_5_UNIT: A float representing the USD value allocated for a trade with "Size: 1/5". This value scales with the numerator (e.g., 3/5 = 3 * FUNDING_PER_1_5_UNIT USD).
-   MAX_ENTRY_SLIPPAGE_PERCENT: Maximum allowed percentage deviation from signal price for order execution.
-   DEFAULT_TRAILING_STOP_PERCENT: Default percentage for trailing stop calculations.
-   DEFAULT_PROFIT_TAKE_PERCENT: Default profit target percentage for trades.
-   DEFAULT_MAX_LOSS_PERCENT: Default maximum loss percentage for trades.
